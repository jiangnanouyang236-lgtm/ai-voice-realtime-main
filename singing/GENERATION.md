# 歌曲生成基线与交接

> 本文只保存当前有效结论和最短复现路径，不记录完整实验流水账。
> 只维护播放服务时阅读 `singing/README.md` 即可；新增歌曲或音色时再阅读本文和对应
> `singing/scores/<song-id>/manifest.json`。

## 当前基线

当前效果较稳定的路线是：

```text
适配目标音色的演唱片段
  -> 按自然休止切成约 3--13 秒的小段
  -> 提取每段连续 F0、歌词、音符与时值
  -> SoulX-Singer SVS 使用固定目标音色参考生成
  -> 每段选择 Shift 和 Seed
  -> 拼接为约 30 秒成品
  -> 导出 16 kHz mono PCM16 WAV
```

这是一条质量基线，不是最终模型路线。允许替换分离器、F0 提取器或 Singer；偏离基线时，
在歌曲 Manifest 中记录方法和听审结论即可，不要求复制历史实验。

## 已验证的经验

- 连续 F0 比“一字一个离散 MIDI”更能保留转音、滑音、拖拍和节奏，目前是默认唱法控制。
- 目标音色与原唱声区、唱法是否相容，对结果影响很大。女声音色直接模仿低男声原唱容易出现
  男声、错字、未知语言或音色漂移；优先选择声区和表达更相容的翻唱作为唱法来源。
- 约 30 秒单次推理不稳定。按自然休止分段生成更可靠，但每一段都应使用同一份目标音色参考，
  不要把上一段生成结果作为下一段参考。
- Shift 按片段计算，不按整首歌统一计算。`Shift=0` 不保证最像参考人物；当前目标是优先保留
  “这是这个人在唱”的身份感，其次才是绝对音准和演唱技巧。
- Seed 会明显影响音色和发音。保留少量固定候选，逐段生成后听审选择；不假设一个 Seed 能覆盖
  所有歌曲和所有片段。
- 自动指标只能发现格式、音高和明显歌词问题，不能替代真人听审。自然度、角色相似度和异常声线
  仍以听审为最终门禁。

## 最小输入

新增歌曲准备以下内容即可：

1. 一段约 25--35 秒、旋律和歌词清楚的演唱来源；不要求必须是原唱。
2. 与片段严格对应的歌词。
3. 已确认的目标音色参考；建议干净单人语音，约 6--15 秒，无背景音乐和混响。
4. 稳定的歌曲 ID、标题、歌手和常见 ASR 错字别名。

源文件、模型和生成 WAV 不提交 Git；Git 只保存可复用谱面、参数、目录和哈希。

## 默认处理步骤

1. 先听选片段，确认目标音色与唱法来源大致相容。
2. 必要时做人声分离，避免伴奏污染 F0 和咬字。
3. 按换气、停顿或乐句边界分段，避免为了固定长度切断一个字或长音。
4. 为每段整理 SoulX 输入：`text`、`phoneme`、`duration`、`note_pitch`、`note_type`、连续 `f0`。
5. 先估算使旋律进入目标音色舒适区的 Shift，再围绕该值生成少量候选；遇到音色漂移时，
   优先调整声区和唱法来源，不要只增加 Seed 数量。
6. 使用固定目标音色参考生成所有分段，从固定候选 Seed 中逐段选择。
7. 按原始时间关系拼接，保留自然休止；不要用上一段音频续写下一段。
8. 导出并验证 16 kHz、单声道、PCM16 WAV，随后更新谱面 Manifest 和歌曲目录。

当前实验曾使用的生成环境位于
`chase@10.10.6.121:/home/chase/datasets/wzk/deploy/tts-sing`。这是实验位置而不是运行时依赖；
接手时先确认目录、代码版本、模型和 GPU 状态，不要根据本文自动下载或重建模型。

## 需要保存的产物

```text
singing/
  catalog.json
  voices.json
  scores/<song-id>/
    manifest.json
    chunks/chunk-XX.soulx.json

SINGING_AUDIO_ROOT/
  <voice>/<song-id>-<slug>.wav
```

Manifest 至少记录：生成引擎、控制方式、唱法来源、目标音色、分段歌词、时长、Shift、候选及
选中 Seed、成品格式和 SHA-256。新增音色时优先复用 `chunks/*.soulx.json`，只重新做音色适配、
Shift/Seed 候选和听审。

## 验收与状态

- `IMPLEMENTED`：谱面、目录、格式和离线测试通过。
- `OWNER_LISTENING_ACCEPTED`：用户已听审接受具体音色的具体成品。
- `LIVE_VERIFIED`：部署后的真实 Gateway/WebRTC 链路有合规证据。

最低听审项：歌词可懂、无异常男女声切换、无未知语言、目标人物身份感可辨、分段衔接自然、
无周期性杂音。听审失败时保留候选和原因，不用为了“跑通”改成通过。

## 不必重复的旧路线

- 仅靠离散 MIDI 可以验证旋律，但当前自然唱法明显弱于连续 F0，不作为默认生成路径。
- SVC 能快速替换音色，但会继承原唱咬字、气息和表达，目前不作为产品基线。
- 一次生成完整 30 秒曾出现音色漂移和异常语言；除非模型或推理方式有明确变化，否则继续分段。
- 不通过无限增加音符密度、Seed 数量或人工逐音精修来掩盖输入适配问题；批量歌曲方案应保持
  自动化，并把少量人工工作留给选片和最终听审。

## 接手检查清单

- 先读本文件，再读目标歌曲 Manifest；无需回看全部历史会话。
- 确认目标音色参考、唱法来源、分段和歌词是否齐全。
- 复用已有谱面时，不重新提取歌曲结构。
- 新实验只改变一个主要变量，并保存 A/B 成品和听审结论。
- 更新 Catalog 后校验音频格式、时长、SHA-256、别名和实际文件路径。
- 不把本地生成成功描述为线上或硬件验证。

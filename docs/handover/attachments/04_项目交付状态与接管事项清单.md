### 2. Go 健康探针：已解决的历史问题

9月11日曾观察到 Docker unhealthy：健康探针使用旧镜像路径，尝试启动第二个监听进程；主服务 HTTP 健康仍成功。

**9月14日补充资料报告已将探针改为实际挂载 binary 路径，服务为 running/healthy。** 此项按已修复记录，不继续列为当前未解决问题。本次附件整理没有再次登录复测。

现场挂载路径修复不要求修改仓库通用镜像的程序路径，两者部署方式不同。
